# CHANGELOG
## [1.0.0] - 2026-05-04
### Добавлено
- **Система аутентификации и авторизации**
  - Регистрация новых пользователей с валидацией email и пароля
  - Вход в систему с проверкой credentials
  - Сессионная аутентификация
  - Защита страниц через проверку авторизации
- **Ролевая модель пользователей**
  - Две роли: администратор (admin) и обычный пользователь (user)
  - Разграничение доступа к функциям на основе ролей
  - Проверка ролей в коде с функциями requireLogin() и requireRole()
- **Управление каталогом автомобилей**
  - Просмотр списка всех автомобилей с пагинацией
  - Детальная страница автомобиля с фото и характеристиками
  - Добавление новых автомобилей (только администраторы)
  - Редактирование информации об автомобилях (только администраторы)
  - Удаление автомобилей (только администраторы)
  - Загрузка фотографий автомобилей
- **Система заявок**
  - Подача заявок на покупку автомобилей
  - Управление заявками администраторами
  - Изменение статуса заявок (new, pending, approved, rejected)
  - Просмотр заявок пользователями
- **REST API**
  - `GET /api/read.php` - получение списка автомобилей с лимитом
  - `POST /api/create.php` - создание нового автомобиля
  - `PUT /api/update.php` - обновление данных автомобиля
  - `DELETE /api/delete.php` - удаление автомобиля
  - JSON ответы с кодами HTTP статусов
  - Валидация данных на всех endpoints
- **База данных**
  - 7 таблиц: users, cars, applications, car_history, car_reviews, car_service, logs
  - Связи между таблицами (foreign keys)
  - Структура для истории обслуживания автомобилей
  - Система логирования действий пользователей
- **Интерфейс пользователя**
  - Адаптивный дизайн с Bootstrap
  - Главная страница с каталогом автомобилей
  - Страница деталей автомобиля
  - Панель управления для администраторов
  - Кредитный калькулятор
  - Формы для всех операций CRUD

- **Логирование и аудит**
  - Запись всех действий администраторов в таблицу logs
  - Отслеживание добавления, редактирования и удаления автомобилей
  - Логирование изменений статуса заявок

- **Документация**
  - Техническая документация (DOCUMENTATION.md)
  - Руководство пользователя (USERGUIDE.md)
  - Документация API (API_DOCUMENTATION.md)
  - Структура базы данных (DATABASE_STRUCTURE.md)
  - Роли пользователей (USER_ROLES.md)
  - README.md с инструкцией установки
- **Безопасность**
  - Хеширование паролей с password_hash()
  - Валидация всех входных данных
  - Защита от SQL-инъекций через PDO prepared statements
  - Проверка прав доступа на всех защищённых страницах
  - CORS настройки для API
